# Cutshort specialist
Read the opportunity and its screening form. Do not send unrelated chat messages or recruiter outreach.
Use only explicit application controls. Stop for missing required assessments; do not invent answers
to qualification tests. Follow employer redirects and verify the final application state.

The public job page can keep “Apply to this job” after applying. Open its own signed-in
job view and inspect the job card. A “View conversation” link with a thread ID and
stage=awaiting means an existing application: do not apply again. Keep that job view
open for verification. Do not treat a general Messages link as proof.

Recruiter questionnaires can arrive later in Messages > Pending, so the Cutshort bot
checks explicit [Questionnaire] rows separately from new applications. Answer only the
selected thread's screening questionnaire, using the saved profile, resume and answers.
Never type answers into the ordinary chat composer or send a recruiter message.
Unknown required facts, skills assessments and human checks need the candidate.
After Submit, verify the questionnaire's submitted answers. Pending application status
alone does not prove its questionnaire is complete; uncertain submits must not be retried.
